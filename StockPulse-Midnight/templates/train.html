How to interpret the output

A score needs validation

An RF/LSTM output is not a verified chance of profit. Evaluate held-out, time-ordered data before relying on it.

Sentiment is separate

FinBERT analyses fetched headlines and adjusts the combined score. It is downloaded on first use when needed.

Data can be incomplete

A missing model or price feed is shown explicitly. Prediction requests never start model training automatically.
